# Тест-кейсы: Оформление заказа (SauceDemo)

| ID | Заголовок | Приоритет | Предусловия | Шаги | Ожидаемый результат | Тип |
|---|---|---|---|---|---|---|
| TC-C-01 | Переход к оформлению при непустой корзине | P0 | В корзине есть минимум 1 товар | 1) Нажать `Checkout` | Переход на `checkout-step-one.html` | Позитивный |
| TC-C-02 | Успешное оформление заказа | P0 | На шаге ввода данных | 1) Ввести `First Name=Test` 2) `Last Name=User` 3) `Zip/Postal Code=12345` 4) `Continue` | Переход на `checkout-step-two.html` (Overview) | Позитивный |
| TC-C-03 | Проверка итоговой суммы (Overview) | P0 | На странице Overview | 1) Проверить `Item total` 2) Проверить `Tax` 3) Проверить `Total` | `Item total + Tax = Total` | Позитивный |
| TC-C-04 | Завершение заказа | P0 | На странице Overview | 1) Нажать `Finish` | Переход на `checkout-complete.html`, сообщение об успешном оформлении | Позитивный |
| TC-C-05 | Возврат на главную после успешного заказа | P1 | Заказ завершён | 1) Нажать `Back Home` | Переход на `inventory.html`, корзина пуста/в исходном состоянии | Позитивный |
| TC-C-06 | Checkout с пустым First Name | P1 | На шаге ввода данных | 1) Поле `First Name` пустое 2) Остальные валидны 3) `Continue` | Появляется сообщение об ошибке, переход не происходит | Негативный |
| TC-C-07 | Checkout с пустым Last Name | P1 | На шаге ввода данных | 1) `Last Name` пустое 2) `Continue` | Сообщение об ошибке | Негативный |
| TC-C-08 | Checkout с пустым Zip/Postal Code | P1 | На шаге ввода данных | 1) `Zip` пустое 2) `Continue` | Сообщение об ошибке | Негативный |
| TC-C-09 | Возврат на корзину со шага Checkout: Your Information | P2 | На `checkout-step-one.html` | 1) Нажать `Cancel` | Возврат в корзину | Позитивный |
| TC-C-10 | Возврат на Inventory со шага Overview | P2 | На `checkout-step-two.html` | 1) Нажать `Cancel` | Возврат на `inventory.html` (товары могут остаться) | Позитивный |
