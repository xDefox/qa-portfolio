# Тест-кейсы: Каталог и корзина (SauceDemo)

| ID | Заголовок | Приоритет | Предусловия | Шаги | Ожидаемый результат | Тип |
|---|---|---|---|---|---|---|
| TC-I-01 | Отображение карточек товара | P1 | Авторизован `standard_user` | 1) Открыть `inventory.html` | У каждого товара: название, цена, кнопка Add to cart, картинка | Позитивный |
| TC-I-02 | Сортировка: Name A-Z → Z-A | P1 | Авторизован `standard_user` | 1) Выбрать `Name (Z to A)` в дропдауне сортировки | Товары отсортированы по названию от Z к A | Позитивный |
| TC-I-03 | Сортировка: Price low-high / high-low | P1 | Авторизован `standard_user` | 1) `Price (low to high)` 2) `Price (high to low)` | Цена корректно отсортирована | Позитивный |
| TC-I-04 | Добавить товар в корзину | P0 | Авторизован `standard_user` | 1) Нажать `Add to cart` на любом товаре | Кнопка меняется на `Remove`, бейдж корзины = +1 | Позитивный |
| TC-I-05 | Удалить товар из корзины (инвентарь) | P1 | Товар добавлен | 1) Нажать `Remove` в карточке товара | Бейдж корзины уменьшается, кнопка `Add to cart` | Позитивный |
| TC-I-06 | Переход в корзину | P0 | Авторизован `standard_user` | 1) Нажать иконку корзины | Открывается `/cart.html`, отображаются добавленные товары | Позитивный |
| TC-I-07 | Удалить товар из корзины | P1 | В корзине есть товар | 1) В корзине нажать `Remove` | Товар удаляется из списка | Позитивный |
| TC-I-08 | «Continue Shopping» возвращает в каталог | P1 | В корзине | 1) Нажать `Continue Shopping` | Перенаправление на `inventory.html` | Позитивный |
| TC-I-09 | Переход в детальную карточку товара | P2 | Авторизован `standard_user` | 1) Кликнуть по названию товара | Открывается `/inventory-item.html?id=...` с деталями | Позитивный |
| TC-I-10 | Добавить/удалить из детальной карточки | P2 | На детальной странице товара | 1) `Add to cart` → бейдж +1 2) `Remove` → бейдж -1 | Кнопки и бейдж работают корректно | Позитивный |
