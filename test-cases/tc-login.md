# Тест-кейсы: Авторизация (SauceDemo)

| ID | Заголовок | Приоритет | Предусловия | Шаги | Ожидаемый результат | Тип |
|---|---|---|---|---|---|---|
| TC-L-01 | Успешная авторизация (standard_user) | P0 | Открыта [страница логина](https://www.saucedemo.com/) | 1) Ввести `standard_user` 2) Ввести `secret_sauce` 3) Нажать `Login` | Перенаправление на `inventory.html`, отображается каталог товаров | Позитивный |
| TC-L-02 | Блокировка пользователя (locked_out_user) | P1 | Открыта страница логина | 1) Ввести `locked_out_user` 2) Ввести `secret_sauce` 3) Нажать `Login` | Появляется сообщение об ошибке: `Sorry, this user has been locked out.` | Негативный |
| TC-L-03 | Авторизация problem_user | P1 | Открыта страница логина | 1) Ввести `problem_user` 2) Ввести `secret_sauce` 3) Нажать `Login` | Авторизация проходит (дальнейший флоу проверять отдельно — возможны дефекты) | Позитивный |
| TC-L-04 | Авторизация error_user | P1 | Открыта страница логина | 1) Ввести `error_user` 2) Ввести `secret_sauce` 3) Нажать `Login` | Авторизация проходит | Позитивный |
| TC-L-05 | Авторизация visual_user | P1 | Открыта страница логина | 1) Ввести `visual_user` 2) Ввести `secret_sauce` 3) Нажать `Login` | Авторизация проходит | Позитивный |
| TC-L-06 | Пустые логин и пароль | P1 | Открыта страница логина | 1) Оставить поля пустыми 2) Нажать `Login` | Сообщение об ошибке (обязательность полей) | Негативный |
| TC-L-07 | Только логин, пароль пуст | P1 | Открыта страница логина | 1) Ввести `standard_user` 2) Оставить пароль пуст 3) Нажать `Login` | Сообщение об ошибке | Негативный |
| TC-L-08 | Логин пуст, только пароль | P1 | Открыта страница логина | 1) Оставить логин пуст 2) Ввести `secret_sauce` 3) Нажать `Login` | Сообщение об ошибке | Негативный |
| TC-L-09 | Неверные креды | P1 | Открыта страница логина | 1) Ввести `wrong_user` 2) Ввести `wrong_pass` 3) Нажать `Login` | Сообщение об ошибке | Негативный |
