# BR-002: Ошибка при оформлении заказа для problem_user (поле Last Name)

**ID:** BR-002  
**Название:** Поле `Last Name` не принимает ввод при оформлении заказа (problem_user)  
**Статус:** Open  
**Найдено:** 2026-10-10  
**Сайт:** https://www.saucedemo.com/  
**Пользователь:** `problem_user`  
**Тип:** Functional  
**Severity:** Critical  
**Priority:** P0

## Окружение

| Параметр | Значение |
|---|---|
| ОС | Linux |
| Браузер | Chrome 140 |
| Разрешение | 1920x1080 |

## Предусловия

1. Авторизоваться под `problem_user`
2. Добавить хотя бы 1 товар в корзину
3. Перейти в корзину → `Checkout`

## Шаги воспроизведения

1. На странице `checkout-step-one.html` заполнить `First Name = Test`
2. Попробовать ввести `Last Name = User`
3. Ввести `Zip/Postal Code = 12345`
4. Нажать `Continue`

## Ожидаемый результат

Можно корректно заполнить все поля и перейти на `checkout-step-two.html`.

## Фактический результат

Поле `Last Name` блокирует ввод/не сохраняет значение. Переход не происходит либо происходит с ошибкой валидации.
