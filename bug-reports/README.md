# Bug-reports

Здесь собраны примеры баг-репортов, оформленных по единому шаблону ([docs/bug-report-template.md](../docs/bug-report-template.md)).

| ID | Название | Пользователь | Severity | Priority |
|---|---|---|---|---|
| BR-001 | Некорректная сортировка в каталоге | problem_user | Major | P1 |
| BR-002 | Блокировка поля Last Name при оформлении заказа | problem_user | Critical | P0 |
| BR-003 | Расхождения при работе с корзиной | error_user | Major | P1 |

Рекомендация: при реальном прогоне фиксировать фактические результаты с приложением скриншотов/видео.
