# BR-001: Сортировка в каталоге работает некорректно для problem_user

**ID:** BR-001  
**Название:** Невозможно изменить сортировку товаров (Name/Price) при авторизации под `problem_user`  
**Статус:** Open  
**Найдено:** 2026-10-10  
**Сайт:** https://www.saucedemo.com/  
**Пользователь:** `problem_user` (пароль `secret_sauce`)  
**Тип:** Functional  
**Severity:** Major  
**Priority:** P1

## Окружение

| Параметр | Значение |
|---|---|
| ОС | Linux |
| Браузер | Chrome 140 |
| Разрешение | 1920x1080 |

## Предусловия

1. Открыть `https://www.saucedemo.com/`
2. Авторизоваться под `problem_user`

## Шаги воспроизведения

1. На странице `inventory.html` выбрать в дропдауне сортировки `Name (Z to A)`
2. Обратить внимание на порядок товаров
3. Попробовать `Price (low to high)`, `Price (high to low)`

## Ожидаемый результат

Порядок товаров меняется в соответствии с выбранным критерием сортировки.

## Фактический результат

Сортировка либо не меняет порядок, либо меняется некорректно. Поведение расходится с тем, что наблюдается у `standard_user`.

## Вложения

(скриншот рекомендовано приложить при реальном прогоне)

## Комментарий

`problem_user` в SauceDemo намеренно имеет «сломанный» функционал — хорошая иллюстрация того, что дефект надо отличать от ожидаемого поведения при разных условиях. Данный случай рассматривается как дефект в сравнении с эталонным поведением (`standard_user`).
