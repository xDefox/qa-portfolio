# BR-003: Некорректное поведение при работе с корзиной (error_user)

**ID:** BR-003  
**Название:** Ошибки при добавлении/удалении товара в корзине для `error_user`  
**Статус:** Open  
**Найдено:** 2026-10-10  
**Сайт:** https://www.saucedemo.com/  
**Пользователь:** `error_user`  
**Тип:** Functional  
**Severity:** Major  
**Priority:** P1

## Окружение

| Параметр | Значение |
|---|---|
| ОС | Linux |
| Браузер | Chrome 140 |
| Разрешение | 1920x1080 |

## Предусловия

1. Авторизоваться под `error_user`
2. Открыть страницу `inventory.html`

## Шаги воспроизведения

1. Нажать `Add to cart` на нескольких товарах
2. Обратить внимание на счётчик корзины
3. Удалить товар через `Remove`
4. Перейти в корзину и проверить содержимое

## Ожидаемый результат

Счётчик и список товаров синхронизируются: добавление/удаление отражается корректно.

## Фактический результат

Возможны расхождения между фактически добавленными товарами, счётчиком корзины и содержимым `cart.html`.
