# Чек-лист: SauceDemo

**Цель:** проверка ключевых сценариев покупателя  
**Сайт:** [saucedemo.com](https://www.saucedemo.com/)  
**Выполнять:** вручную (или автоматизировать на основе чек-листа)

## 1. Авторизация

| ID | Проверка | Ожидаемый результат | Статус (PASS/FAIL/NA) |
|---|---|---|---|
| CH-01 | Авторизация с валидными кредами (`standard_user/secret_sauce`) | Успешный вход на страницу Inventory | |
| CH-02 | Авторизация с `locked_out_user` | Сообщение о блокировке пользователя | |
| CH-03 | Авторизация с `problem_user` | Вход возможен (поведение может быть нестабильным) | |
| CH-04 | Авторизация с пустым логином/паролем | Появляется сообщение об ошибке | |
| CH-05 | Авторизация с невалидными данными | Сообщение об ошибке | |

## 2. Каталог (Inventory)

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| CH-06 | Отображение товаров (наименование, цена, изображение) | Товары корректно отображаются | |
| CH-07 | Фильтрация (Name A-Z / Z-A / Price low-high / high-low) | Сортировка работает корректно | |
| CH-08 | Добавить товар в корзину с карточки товара | Кнопка меняется на «Remove», счётчик корзины увеличивается | |
| CH-09 | Удалить товар из корзины с карточки | Счётчик и кнопка возвращаются в исходное | |
| CH-10 | Переход на карточку товара (по названию/картинке) | Открывается детальная карточка | |

## 3. Корзина (Cart)

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| CH-11 | Переход в корзину по иконке | Открывается страница корзины, корректный список товаров | |
| CH-12 | Отображение цены и количества | Цены и наименования совпадают с добавленными | |
| CH-13 | Удалить товар из корзины | Товар исчезает из корзины | |
| CH-14 | Кнопка «Continue Shopping» возвращает в каталог | Возврат на Inventory без потери состояния | |
| CH-15 | Кнопка «Checkout» | Переход на страницу Your Information | |

## 4. Оформление заказа (Checkout)

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| CH-16 | Заполнение валидных данных (First Name, Last Name, Zip) | Переход на Checkout Overview | |
| CH-17 | Пустые поля → ошибка | Валидационное сообщение | |
| CH-18 | Проверка Summary: Item total, Tax, Total | Суммы корректно пересчитаны | |
| CH-19 | Кнопка «Finish» | Переход на «Checkout Complete!» | |
| CH-20 | Кнопка «Back Home» после успешного заказа | Возврат на Inventory | |

## 5. Негативные проверки

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| CH-21 | Прямой переход в корзину без добавления | Корзина пуста | |
| CH-22 | Работа UI при возвратах между страницами | Нет «битых» переходов/кеш-эффектов | |
| CH-23 | Базовая проверка на орфографию/надписи | Тексты читаемы, нет явных опечаток | |
